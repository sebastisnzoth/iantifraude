# AntiGolpe AI
MVP web/PWA de evaluación orientativa de posibles fraudes, en español, portugués e inglés. Motor heurístico, sin IA generativa. No certifica seguridad.

Ejecutar `npm start` y abrir http://localhost:8080. Pruebas: `npm test` (Node 20+).

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

El análisis es local. OCR opcional descarga recursos externos. No se visitan enlaces analizados. El historial optativo guarda fecha, nivel y cantidad de señales. Falsos positivos y negativos posibles. Pendiente validar OCR, PWA y navegadores reales.
